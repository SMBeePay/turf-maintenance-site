TEXAS TURF MAINTENANCE — PIXEL-PERFECT INDIVIDUAL LOGOS

Every PNG in this folder is a direct 1:1 pixel crop from the approved logo sheet supplied by the user.
No artwork has been redrawn, traced, retyped, recolored, smoothed, or rescaled.

Each SVG is a pixel-perfect SVG container that embeds its matching PNG at native size. This guarantees the SVG looks exactly like the approved logo-sheet artwork, but it is not a path-based vector redraw.

The crop coordinates and native pixel dimensions are recorded in manifest.json.
